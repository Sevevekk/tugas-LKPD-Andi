C. AKTIVITAS 1: EKSPERIMEN 10 + 20

Prediksi hasil sebelum menjalankan kode. Jalankan kode dan amati.

Simpan file sebagai lkpd_string_number_nama.js.

let a = "10";
let b = "20";
console.log(a + b);

Pertanyaan & Jawaban:

  • Apa output program? Outputnya adalah 1020.
  • Mengapa hasil tersebut terjadi? Karena variabel a dan b bertipe String. Operator + pada String digunakan untuk penggabungan teks bukan penjumlahan aritmatika.
  • Apakah a dan b bertipe Number? Tidak, keduanya bertipe String.
  • Uji sekarang. Apakah prediksimu benar? Jelaskan: Prediksi saya sesuai karena nilai string "10" dan "20" digabungkan sehingga membentuk string "1020".

D. AKTIVITAS 2: MENEMUKAN TIPE DATA

Jalankan:

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
Variabel Prediksi Hasil typeof Kesimpulan
nama string string Karena fungsi typeof hanya menampilkan variable bukan hasil nilai tipe data variablenya,jadi yang muncul string.
umur number number sama yang keluar bukan hasil nilai tapi tipe data variabelnya yaitu number.

Temuan: Apa perbedaan String dan Number berdasarkan eksperimenmu?

String adalah tipe data teks yang diapit tanda petik dan jika dihubungkan dengan operator + akan digabungkan. Number adalah tipe data angka yang dapat digunakan untuk operasi hitung matematika.

G. TANTANGAN - PROGRAM HITUNG NILAI

Buat program dengan input nilai tugas, UTS, dan UAS. Konversikan semua input menggunakan Number(), lalu hitung rata-rata dengan rumus (tugas + UTS + UAS) / 3.

let tugas = Number(prompt("Masukkan nilai Tugas:"));
let uts = Number(prompt("Masukkan nilai UTS:"));
let uas = Number(prompt("Masukkan nilai UAS:"));

let rataRata = (tugas + uts + uas) / 3;
console.log("Rata-rata nilai = " + rataRata);

Algoritma saya:

  1. Mengambil input nilai tugas, UTS, dan UAS dari pengguna menggunakan prompt().
  2. Mengonversi seluruh input string menjadi tipe Number menggunakan fungsi Number().
  3. Menhitung rata-rata menggunakan rumus (tugas + uts + uas) / 3.
  4. Menampilkan hasil nilai rata-rata ke konsol/layar dengan console.log().

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Karena prompt() selalu mengembalikan data bertipe String.maka nilainya harus dikonversi ke angka agar operasi matematika bekerja dengan benar.
Apa perbedaan "10" dengan 10? "10" bertipe String (teks), sedangkan 10 bertipe Number (angka numerik).
Apa yang terjadi jika lupa Number()? Jika lupa memakai Number(), nilai yang seharusnya menjadi angka sering tetap dianggap string, sehingga operasi matematika berubah menjadi penggabungan string atau mengha
